## 11. 给你一个最短学习路线

你不用一口气学完整个计算机网络。按你现在的现场问题，建议这样学：

```
第1天：IP地址、子网掩码、网关第2天：交换机、路由器、WAN/LAN第3天：NAT、端口映射、防火墙第4天：VLAN、工业网络隔离第5天：端口镜像、Wireshark抓包
```

学完这些，你就能听懂现场网络方案了。
